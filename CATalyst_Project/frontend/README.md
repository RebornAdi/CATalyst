# CATalyst Proper React Frontend

This is a React/Vite version of the uploaded CATalyst UI. The visual structure and dark Caterpillar-style design are retained, while the frontend is now a real React application.

## Backend

The frontend talks to Module 3:

http://127.0.0.1:8003

Module 3 then connects to Module 1 and Module 2.

## Run

```bash
cd frontend1
npm install
npm run dev
```

Open:

http://127.0.0.1:5173

## Demo

Make sure Module 1, Module 2 and Module 3 are running first.

Use the scenario selector and the quick questions. The response, risk, health, confidence, evidence, correlation and recommended action come from the real Module 3 response.
